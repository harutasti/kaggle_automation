# santa-2025 competition assets

This directory holds competition-specific guidance and helper utilities.

Contents:
- `profile.yaml`: prompt guidance for KSE/WAA.
- `tools.py`: helper CLI for validation and local checks.
- `knowledge/`: auto-populated best results and saved submissions.

Use from a worktree:
```
uv run competitions/santa-2025/tools.py --help
```
